# Valerie · F18–F22 · candidata cinematográfica

Rama independiente de F17, con el mismo arte y los dos peluches aprobados. Lectura manual predeterminada, modo Cine voluntario, ocho decisiones reversibles y 19 capítulos. La pregunta sigue siendo exactamente «Valerie, ¿quieres ser mi novia?», sin respuesta digital.

Abre VALERIE_CUENTO_CINEMATOGRAFICO.html con doble clic: todo está incorporado. dist/ es el sitio modular. src/, assets/, references/, brief/, legacy/, scripts/ y tests/ permiten editar y reconstruir. Se preservan los nueve originales ASCII como respaldo y las ilustraciones/fotos/carta originales. BASE_F17.json identifica el ZIP de partida.

Node.js 22+: npm run build genera ambas versiones y verifica manifiestos. npm test ejecuta 24 contratos sin instalar dependencias. Para navegador: npm ci, Edge y servidor activo; npm run test:browser. Esa es la lista de pruebas vigente; las de fases antiguas se conservan como historia. npm run phone sirve el proyecto en tu red local, puerto 4188. Instrucciones en README_WINDOWS.md.

npm run package y npm run package:site crean los paquetes completos y modular privado. No hay publicación ni QR. HOSTING_PRIVADO.md conserva el servidor HTTPS que autentica HTML y todos los activos. Revisión artística por el autor y Safari/iPhone/Android físicos pendientes.
