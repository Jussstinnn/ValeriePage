# VALERIE — CINEMATIC REBIRTH RC07

Extrae el ZIP y abre VALERIE_OFFLINE.html con Edge o Chrome. La narración aparece dentro de la película; «Releer» permite contemplarla aparte. Desliza para recorrer los mundos o utiliza los controles permanentes. Sonido y tacto son opcionales, apagados al iniciar.

- COMO_EJECUTAR_WINDOWS.md: abrir, editar, compilar y probar.
- CAMBIOS_RC07.md: cambios y límites verificados.
- CHECKPOINT_RC07.md: arquitectura y continuidad.
- src/personal-story.js: campos para frases reales, dedicatorias, carta y firma.
- src/ y scripts/: código completo del director y las derivaciones.
- engines/ y memories/: nueve originales íntegros, incluidas sus fotografías.
- dist/: producción y nueve derivados ejecutables. VALERIE_OFFLINE.html integra todo en un archivo.

Node.js 22+: npm run build; npm start. Sin dependencias para compilar o servir. npm ci instala únicamente las herramientas de pruebas. No hay backend, analítica, CDN ni subida de fotos. RC06 permanece intacta en su proyecto independiente.
